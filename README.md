# sB Hub v1 modular build

Built from the uploaded source's verified structure.

Verified source details:
- 500x600 `sB Hub v1` window
- seven tabs: `main`, `automation`, `stats`, `esp`, `notify`, `spy`, `settings`
- persistent `sBHub_v1_Settings.json` config
- automation state for Auto Train/Rebirth/Jungle Rock/Egg/Ultimates/Size/Speed
- ESP, coordinates, notifications, overlays, stats and server-spy state
- RightShift GUI toggle and draggable title bar

The chat file-search system exposes the uploaded source as retrieved chunks rather than a raw filesystem file. Therefore this package does NOT falsely claim to be a byte-for-byte extraction of source sections that were not exposed. The original uploaded source remains authoritative for those sections.
